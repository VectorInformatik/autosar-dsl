# AUTOSAR DSL

This repository provides official releases of the AUTOSAR DSL CLI (Command Line Interface), which contains both the language server and the language compiler tools.

The repository acts as the provider of the artifacts for the [AUTOSAR DSL VS Code extension](https://github.com/VectorInformatik/vscode-autosar-dsl).

The official development package can be downloaded from the [Vector Download Portal](https://www.vector.com/de/de/support-downloads/download-center/#product=%5B%2278310%22%5D&tab=1&pageSize=15&sort=date&order=desc).
